## 通行密钥「This is an invalid domain.」根因与优雅降级（2026-10-15）
- **根因**：WebAuthn 的 RP ID 必须是**合法域名**，IP 字面量一律非法（含 127.0.0.1 / 局域网 IP / [::1]）；
  且页面须处于安全上下文（https 或 **http://localhost**）。用户用 `http://127.0.0.1/` 访问 →
  `PasskeyService::rpId()` 回退成 `127.0.0.1` → 浏览器在 `navigator.credentials.create` 直接抛
  `SecurityError: This is an invalid domain.`。**不是代码 bug，是访问域名约束**。
- 新增 `PasskeyService::domainIssue()` / `domainUsable()`：返回 null 或
  `['code'=>ip|insecure|host|ip_rpid|mismatch|rp_empty,'message','hint']`；
  判定顺序：访问 host 是 IP → 非 https 且非 localhost → 单标签内网主机名 → rpId 自身是 IP → host 与 rpId 不匹配。
  辅助方法 `requestHost()/isIpLiteral()/isHttps()`（兼容 X-Forwarded-Host/Proto）。
- `registerOptions()/authOptions()` 前置拦截 → 返回中文原因（不再生成注定失败的 options）。
- `passkey_status` API 增补 `domain_ok/domain_issue/domain_reason/domain_hint`（公开、无敏感信息）。
- `security.php`：域不可用时渲染 `.alert-warn`（原因 + 修复指引）并 **disabled**「添加通行密钥」按钮（title 给原因）；
  已有密钥列表仍可查看/删除（list/rename/delete 不受域限制）。JS 用 `DOMAIN_BLOCKED` 避免再误报「浏览器不支持」。
- `login.php`：`$passkeyUsable = $passkeyOn && PasskeyService::domainUsable()` 同时控制
  `autocomplete="username webauthn"`、通行密钥按钮渲染与 JS 变量。
- `passkey.js`：新增 `domainIssue()/domainMessage()`（ip/insecure/host），`isSupported()` 纳入域判定；
  `register()/auth()` 前置拒绝 + `translateError()` 把 SecurityError / NotAllowedError / InvalidStateError 翻成中文，
  不再把英文原报错甩给用户。引用处加 `?v=20261015-pk`。
- `SettingsSchema`：`passkey_enabled` / `passkey_rp_id` 帮助文案修正（原写「127.0.0.1 除外」是错的）。
- 回归：`node tools/passkey_domain_check.js` → **23/23**（IP 源降级 + localhost 源 CDP 虚拟认证器走通注册/列表/删除）；
  `node tools/passkey_e2e_test.js` → 8/8；`tools/member_layout_check.js` → 89/89。
  前置：`php -S 127.0.0.1:8099 -t public`（localhost 与 127.0.0.1 两种访问都测）。
- 环境坑：phpStudy Nginx 的本站 vhost 是 `127.0.0.1_80.conf`（server_name 仅 127.0.0.1，root 本项目 public，PHP-FPM 9001）；
  `localhost` 落在 `0localhost_80.conf`（phpStudy 占位站 + phpMyAdmin，root D:/phpstudy_pro/WWW）→ `http://localhost/` 返回 403。
  故本机要用通行密钥：①临时 `php -S 127.0.0.1:8099 -t public` 访问 http://localhost:8099；
  ②给本站 vhost 增开 `listen 8099; server_name localhost`（纯新增、不影响现有站点）；③线上用 HTTPS 域名。
